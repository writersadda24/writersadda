# Installation and Troubleshooting Guide — Portfolio Sample

**Status:** Work in progress · **Type:** Self-directed demonstration project

## Goal

Document a repeatable local setup for a small Python web application.

## Prerequisites

- Python 3.10 or newer
- Git (optional)
- Terminal or PowerShell

## Example setup workflow

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

> These are example commands. Add the actual application repository, dependency file, execution command, and verification steps before marking this guide complete.

## Planned troubleshooting

| Symptom | Investigation |
| --- | --- |
| `python` not recognized | Check Python installation and PATH |
| PowerShell activation blocked | Review execution policy and approved alternatives |
| Package installation fails | Verify interpreter, network, and dependency versions |
