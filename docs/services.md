# Technical documentation services

Practical writing and content support for software and technology teams. We can take on a defined deliverable or help you identify the highest-value place to begin.

## API and developer documentation

Help developers understand your product and integrate with confidence.

- API references and endpoint guides
- Authentication, errors, and request/response examples
- SDK and integration guides
- Developer quickstarts and tutorials
- OpenAPI review and documentation structure

## Product and AI documentation

Make product workflows and technical concepts easier to follow for developers and technical users.

- Installation, configuration, and upgrade guides
- User and administrator documentation
- AI/ML and retrieval-augmented generation workflows
- Data ingestion, retrieval, and model integration guides
- Troubleshooting and known limitations

## Documentation systems and audits

Improve the way your content is organized, reviewed, and maintained.

- Content and information architecture audits
- Docs-as-code setup and Markdown migration
- Style, terminology, and consistency reviews
- Documentation backlog assessment and prioritization
- Editorial workflows and subject-matter review templates

## How engagements work

We agree on the audience, scope, access, reviewers, and deliverables before writing begins. Work can be scoped as an audit, a single guide, or a small documentation sprint. Availability and timelines are confirmed during the initial conversation.

## What we need from you

Useful inputs include access to the product or a demo, existing documentation, technical contacts for review, and a clear view of the intended audience. If some of these are not ready, we can identify a discovery step first.
